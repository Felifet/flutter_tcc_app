## 📱 Sobre o Projeto

O **Tcc_App** é um aplicativo móvel desenvolvido para **gestão de insumos no cultivo de videiras**, utilizando as tecnologias **Flutter** e **Dart**. 
Este aplicativo foi desenvolvido como trabalho de conclusão de curso, cujo objetivo principal do projeto é ajudar agricultores a **controlar e gerenciar insumos** como fertilizantes, pesticidas e outros recursos essenciais para o cultivo eficiente das videiras.

Junto ao repositório, está anexado um manual de uso da aplicação, onde mostra o fluxo de utilização do APP.


## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

- **Flutter**: Framework para desenvolvimento de aplicações móveis
- **Dart**: Linguagem de programação utilizada no Flutter

## 🔧Algumas das Funcionalidades

- **Gerenciamento de Fertilizantes**: Controle total dos fertilizantes utilizados nas videiras.
- **Controle de Pesticidas**: Gerencie e registre o uso de pesticidas.
- **Monitoramento de Recursos**: Acompanhe outros recursos necessários para o cultivo.

## 🔧Melhorias Futuras:
- **Controle de Funcionários**: Controle total dos funcionários que trabalharam na safra, para auxiliar o pequeno produtor.
- **Controle de Safra**: Detalhar as quantidades colhidas por dia no período da safra e manter um histórico anual de produtividade.
